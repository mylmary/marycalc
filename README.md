# MaryCalc

A simple calculator app with two sections: **Calculator** and **Currency**.

## Features

### Calculator
- Enter numbers and perform basic arithmetic operations.
- View the expression as you enter it.
- Calculate the result when you press equals.

### Currency
- Use the currency section for currency conversion.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

The app is built with React, TypeScript, Vite and Lucide React.
